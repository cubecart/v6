# Product Options

Product options allow you to offer variations of a product such as size, colour, or material. Options are organised into groups, attributes (values), and sets.

## Option Groups

Groups define the type of option (e.g. "Size", "Colour", "Material"). Existing groups are listed in a reorderable table.

| Column | Description |
| --- | --- |
| Arrange | Drag handle to reorder. The order determines the display sequence on the product page. |
| Required | Toggle whether the customer must select a value before adding to cart. |
| Name | The option group name displayed to customers. Editable inline. |
| Type | How the option is presented: dropdown, radio buttons, text field, textarea, etc. Editable inline. |
| Description | An optional description for the option group. Editable inline. |

### Add Option Group

| Field | Description |
| --- | --- |
| Name | The group name (e.g. "Size"). |
| Description | An optional description for the group. |
| Type | Select the input type from the dropdown. |
| Required | Toggle on to make the option mandatory. |

> [!NOTE]
> Deleting a group also deletes all its attributes and removes the option from all products.

## Option Attributes

Attributes are the individual values within a group (e.g. "Small", "Medium", "Large" within the "Size" group). Select a group from the dropdown first, then add attributes by name. Existing attributes are listed under each group heading and can be reordered by dragging.

Only groups with selectable types (dropdown, radio, etc.) appear in the attribute section. Groups with freeform types (text field, textarea) do not have predefined attributes.

### Add Attribute

| Field | Description |
| --- | --- |
| Name | The attribute value name (e.g. "Large"). Type the name and click the add icon. |

## Option Sets

Sets are pre-defined collections of option groups and attributes that can be assigned to products in bulk. Select an existing set from the dropdown to view and manage its members.

### Manage Set Members

Each set shows its members (group + attribute combinations). Remove individual members with the delete icon. Use the **Append Options** multi-select to add additional option values from any group.

### Create Option Set

| Field | Description |
| --- | --- |
| Name | A name for the new option set (e.g. "Clothing Sizes & Colours"). |
| Description | An optional description for the set. |

> [!TIP]
> Use option sets to quickly apply the same set of options (e.g. clothing sizes and colours) to multiple products at once.
