# Product Options

Product options allow you to offer variations of a product such as size, colour, or material. Options are organised into groups, attributes (values), and sets.

## Option Groups

Groups define the type of option (e.g. "Size", "Colour", "Material"). Each group has:

| Field | Description |
| --- | --- |
| Name | The option group name displayed to customers. |
| Type | How the option is presented: dropdown, radio buttons, text field, etc. |
| Required | Whether the customer must select a value before adding to cart. |

Drag and drop to reorder groups. The order determines the display sequence on the product page.

> [!NOTE]
> Deleting a group also deletes all its attributes and removes the option from all products.

## Option Attributes

Attributes are the individual values within a group (e.g. "Small", "Medium", "Large" within the "Size" group). Select a group first, then add attributes. Drag and drop to reorder.

## Option Sets

Sets are pre-defined collections of option groups and attributes that can be assigned to products in bulk. Create a set, add the desired options to it, then assign it to one or more products.

> [!TIP]
> Use option sets to quickly apply the same set of options (e.g. clothing sizes and colours) to multiple products at once.
