# Gift Certificate Settings

Configure how gift certificates work in your store.

## Settings

| Field | Description |
| --- | --- |
| Status | Disabled, Enabled for All Customers, or Enabled for Logged-In Customers Only. |
| Minimum Value | The lowest amount a customer can purchase a gift certificate for. |
| Maximum Value | The highest amount a customer can purchase a gift certificate for. |
| Expiry | Number of days until the gift certificate expires. Leave blank for no expiry. |
| Delivery Method | How the gift certificate is delivered (e.g. email). |
| Weight | Weight value for shipping calculation (if physical delivery). |
| Product Code | The product code used for gift certificate line items in orders. |

## Gift Certificate Images

Upload and manage images displayed on the gift certificate product page. Drag and drop images or use the file manager to assign them. Set a master image for the primary display.

## SEO

| Field | Description |
| --- | --- |
| Meta Title | Custom page title for the gift certificate page in search engines. |
| Meta Description | Description shown in search engine results. |

> [!TIP]
> Gift certificates are automatically generated when a customer completes a purchase. The certificate code and balance are emailed to the recipient.
