# Coupons & Gift Certificates

## Coupons

Create discount codes that customers can enter at checkout.

### Coupon Details

| Field | Description |
| --- | --- |
| Code | The code customers enter at checkout. Alphanumeric characters, dashes, and underscores only. |
| Description | Internal description for your reference. |
| Discount Type | Fixed amount or percentage off. |
| Discount Value | The amount or percentage to discount. |

### Limits

| Field | Description |
| --- | --- |
| Start / Expiry Date | Date range when the coupon is valid. Leave blank for no restriction. |
| Allowed Uses | Maximum number of times the coupon can be used. Set to 0 for unlimited. |
| Per Customer Limit | Maximum uses per individual customer. |
| Minimum Subtotal | The order subtotal must reach this amount before the coupon applies. |
| Apply to Shipping | Include shipping costs in the discount calculation. |
| Free Shipping | Coupon grants free shipping. |
| Exclude Sale Items | Products already on sale are excluded from the discount. |

### Restrictions

Optionally restrict the coupon to specific manufacturers, categories, or shipping methods using the multi-select filters.

### Product Assignment

Assign specific products to the coupon. Choose whether selected products are included (coupon only applies to them) or excluded (coupon applies to everything except them).

## Gift Certificates

Gift certificates are automatically created when a customer purchases a gift certificate product. They appear in the Gift Certificates tab showing the code, remaining balance, expiry date, and the originating order.

> [!TIP]
> A coupon can be manually converted to a gift certificate by linking it to an order number. The coupon must use a fixed amount (not percentage).
