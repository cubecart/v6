# Product Assignment & Bulk Pricing

## Category Assignment

Assign multiple products to one or more categories at once. Select the products and categories, then save.

## Bulk Price Update

Update prices across multiple products or entire categories in one operation.

| Field | Description |
| --- | --- |
| Target | Apply changes to selected products or all products in selected categories. |
| Method | Fixed amount or percentage. |
| Action | Add to, subtract from, or set the price to a specific value. |
| Value | The amount or percentage to apply. |
| Price Field | Which prices to update: all, standard only, sale only, cost only, quantity discounts, or option surcharges. |

> [!NOTE]
> Bulk price changes cannot be undone. Consider exporting your products first as a backup.
