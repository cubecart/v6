# Error Log

View PHP errors and warnings generated by the store.

## Admin Error Log

Errors triggered during your admin sessions. Shows the timestamp and error message. Use the bulk actions to mark entries as read or unread, or clear all admin logs.

## System Error Log

Available to super users only. Shows all system-level errors across the store with severity colour coding:

| Colour | Severity |
| --- | --- |
| Yellow | Notice -- non-critical informational messages. |
| Orange | Warning -- potential issues that should be investigated. |
| Red | Fatal / Parse / Exception -- critical errors requiring immediate attention. |

Each entry shows the error message, the URL where it occurred, and a backtrace (hover for details). Entries can be marked as read/unread in bulk or cleared entirely.

> [!TIP]
> The unread count badge in the tab header shows how many new errors have occurred since you last checked. Review errors regularly to catch issues early.
