# Option Sets Assignment

Bulk-assign option sets to multiple products at once.

## How to Use

1. Select one or more **option sets** from the list.
2. Select one or more **products** to assign them to.
3. Click **Save** to apply the sets to all selected products.

> [!TIP]
> This is useful when adding a new range of products that all share the same options, such as clothing with standard size and colour choices.
