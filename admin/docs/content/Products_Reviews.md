# Product Reviews

## Review List

All product reviews are shown in a table. Sorting is controlled by two dropdowns (field and direction) above the table, not by clicking column headers. Select a field and sort order, then click Go. Click Reset to clear the sort.

| Column | Description |
| --- | --- |
| Checkbox | Select individual reviews for bulk actions. Use the check/uncheck all link below the table. |
| Title | The review headline. Click to edit. A short excerpt of the review text is shown below the title. |
| Product | The product being reviewed. Click to open the product on the storefront. |
| Rating | Star rating from 1 to 5. |
| Name | Reviewer name. If the review was submitted anonymously, "(Anonymous)" is shown after the name. Below the name, the reviewer's email (as a mailto link) and IP address are displayed. |
| Date | The date the review was submitted. |
| Approved | Toggle to approve or reject the review. |

### Bulk Actions (List)

Select one or more reviews using the checkboxes, choose "Delete" from the dropdown, and click Go to delete the selected reviews.

## Add / Edit Review

### Add Review

When adding a review manually, search for a product using the type-ahead field.

### Form Fields

| Field | Description |
| --- | --- |
| Product | Type-ahead search to select the product (add mode only). |
| Status | Toggle to set the review as approved or unapproved. |
| Anonymous | Toggle to mark the review as anonymous. When on, the reviewer's name is hidden on the storefront. |
| Name | Reviewer name. |
| Email | Reviewer email address. |
| Title | The review headline. |
| Content | The review body text. |
| Rating | Star rating from 1 to 5. Click a star to set the rating. |

## Bulk Delete

Remove all reviews matching a specific email address or IP address. Useful for clearing spam reviews.

| Field | Description |
| --- | --- |
| Email | Delete all reviews from this email address. |
| IP Address | Delete all reviews from this IP address. |

## Search

Filter reviews using the search tab.

| Field | Description |
| --- | --- |
| Keywords | Search review titles and content by keyword. |
| Product | Type-ahead search to filter by a specific product. |
| Status | Filter by approval status: all, approved, or unapproved. |
