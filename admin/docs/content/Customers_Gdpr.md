# GDPR Tools

Tools to help comply with data protection regulations such as GDPR.

## Customer Data Report

Enter a customer's email address and click **Create Report** to generate a full report of all data held about them. The report replaces the current page with an HTML document containing:

- Newsletter subscription consent log
- Account details
- Order history
- Newsletter subscriptions
- Product reviews
- Email communication log

The report can be printed or saved using the browser's built-in print/save functions.

## Purge Customer Data

| Action | Description |
| --- | --- |
| Delete customers older than X months | Enter a number of months and click **Go**. Removes all customers who have any order with an order date older than the specified number of months. Note: this includes customers who may also have more recent orders. |
| Delete customers with no orders | Removes all customer accounts that have never placed an order. |
| Delete guest accounts | Removes all unregistered/guest customer records. |

Each purge action requires confirmation before proceeding.

> [!NOTE]
> Purging is permanent. All associated data (addresses, group memberships, newsletter subscriptions) is also deleted. This cannot be undone.
