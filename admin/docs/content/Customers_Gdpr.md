# GDPR Tools

Tools to help comply with data protection regulations such as GDPR.

## Customer Data Report

Enter a customer's email address to generate a full report of all data held about them. The report includes:

- Account details
- Order history
- Newsletter subscriptions
- Product reviews
- Email communication log
- Cookie consent records

The report opens in a new window and can be printed or saved for the customer.

## Purge Customer Data

| Action | Description |
| --- | --- |
| Delete customers older than X months | Removes customers whose most recent order is older than the specified number of months. Enter the number of months and click delete. |
| Delete customers with no orders | Removes all customer accounts that have never placed an order. |
| Delete guest accounts | Removes all unregistered/guest customer records. |

> [!NOTE]
> Purging is permanent. All associated data (addresses, group memberships, newsletter subscriptions) is also deleted. This cannot be undone.
