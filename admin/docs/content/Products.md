# Products

## Product List

The product list shows all products with their thumbnail, name, code, price, stock, and status. Use the filters to narrow by category, status, or alphabetical range. Search by name or product ID.

## Add / Edit Product

### General

| Field | Description |
| --- | --- |
| Product Name | The display name shown on the storefront (required). |
| Product Code | A unique SKU or reference code. Use the auto-generate option to create one automatically. |
| Description | Full product description with rich text formatting. |
| Short Description | A brief summary used in product listings and search results. |
| Status | Enable or disable the product. |
| Featured | Include the product in the featured products section. |
| Latest | Include the product in the latest products section. |
| Live From | Schedule the product to become visible at a future date and time. |

### Pricing

| Field | Description |
| --- | --- |
| Standard Price | The regular selling price. |
| Sale Price | A discounted price. When set, the standard price is shown as a strikethrough. |
| Cost Price | Your cost for the product. Used for profit reporting only -- not displayed to customers. |
| Tax Class | Which tax rate to apply to this product. |
| Tax Inclusive | Whether the entered price already includes tax. |

Use **Quantity Discounts** to offer tiered pricing based on the quantity ordered. Use **Group Pricing** to set different prices for specific customer groups.

### Shipping & Stock

| Field | Description |
| --- | --- |
| Product Weight | Used for shipping calculations. |
| Use Stock Level | Enable inventory tracking for this product. |
| Stock Level | Current quantity in stock. |
| Stock Warning | Threshold at which a low stock warning appears on the dashboard. |
| Digital | Mark as a digital/downloadable product and select the file. |

### Options

Assign option sets or individual options to the product. Each option value can have a price adjustment, weight adjustment, and can be included in the product matrix.

The **Option Matrix** allows you to create unique SKU variants for each combination of options, with separate stock levels and pricing per combination.

### SEO

| Field | Description |
| --- | --- |
| SEO Path | The friendly URL for this product. Auto-generated from the name if left blank. |
| Meta Title | Browser title tag. Aim for 50-60 characters. |
| Meta Description | Search engine description. Aim for 150-160 characters. |

### Categories

Assign the product to one or more categories. Select a primary category which is used for breadcrumb navigation and the canonical URL.

### Images

Upload and manage product images. Drag and drop to upload. The first enabled image becomes the main product thumbnail. Reorder images by dragging.

### Reviews

View and manage reviews for this product. Toggle approval status or delete individual reviews.

### Translations

Add translated versions of the product name, description, and short description for each language enabled in your store.
