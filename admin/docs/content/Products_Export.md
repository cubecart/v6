# Product Export

Export your product catalogue as a CSV file.

## Export Settings

| Field | Description |
| --- | --- |
| Per Page | Number of products per export file. For large catalogues, export in pages. |
| Format | CubeCart format includes all fields in the standard import order. |

## Exported Fields

The CSV includes: product name, status, featured, latest, product code, weight, description, short description, price, sale price, cost price, tax class, tax inclusive, images, stock level, use stock level, stock warning, category ID, manufacturer, UPC, EAN, JAN, ISBN, brand, MPN, GTIN, meta title, meta description, condition, digital file, dimensions, and dimension unit.

> [!TIP]
> Export your products before performing bulk price changes or imports with the replace option, so you have a backup to revert to.
