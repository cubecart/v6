# Languages

Manage installed languages and edit translation strings.

## Installed Languages

| Column | Description |
| --- | --- |
| Status | Enable or disable the language for storefront use. |
| Default | Set as the store's default language. |
| Language | Language name. Click to open the phrase editor. |
| Domain | Optional domain mapping. Assign a specific domain or subdomain to automatically serve this language (e.g. fr.example.com for French). |

## Available Languages

Languages that have been added but not yet installed. Click the install icon to activate a language.

## Phrase Editor

Edit individual translation strings for the selected language. Phrases are organised into groups (e.g. Common, Account, Basket, Catalogue). Select a group from the dropdown to view and edit its strings.

Use the **Search** field to find specific phrases across all groups. Click the pencil icon to edit a phrase, and the revert icon to restore it to the default value.

## Export / Merge

Export database-modified phrases back into the language XML file. Use the **Replace Original** option to overwrite the source XML file with your customised strings.

> [!TIP]
> Domain mapping allows you to run a multilingual store where each language has its own domain or subdomain, and the correct language is selected automatically based on the URL.
