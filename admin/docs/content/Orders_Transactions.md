# Transaction Logs

A global view of all payment transactions across your store, grouped by order.

## Transaction List

| Column | Description |
| --- | --- |
| Order ID | Click to view all transactions for that order. |
| Amount | Transaction amount in store currency. |
| Gateway | The payment processor that handled the transaction. |
| Date | When the transaction was recorded. |

## Search

Search by order number, transaction ID, amount, or gateway name. Partial matches are supported.

## Order Transaction Detail

Click an order to see all its transactions:

| Column | Description |
| --- | --- |
| Transaction ID | The reference from the payment gateway. |
| Status | Transaction status (e.g. pending, completed, failed). |
| Amount | The transaction amount. |
| Gateway | Which payment processor handled it. |
| Date | When the transaction occurred. |
| Notes | Any messages from the payment gateway. |
| Action | Refund or capture actions, if supported by the gateway. |
