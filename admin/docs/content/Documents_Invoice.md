# Invoice Template

Customise the HTML layout used when printing or emailing order invoices.

## Template Editor

The invoice template uses Smarty syntax. Edit the HTML to change the invoice layout, add your logo, or adjust the information displayed. The editor supports both visual and source code editing.

Changes are validated for correct Smarty syntax before saving. A version history is maintained so you can track changes over time.

## Restore to Default

Click **Restore to Default** to reset the invoice template to the original CubeCart layout. This overwrites any customisations.

> [!TIP]
> Use the source code view to make precise HTML changes. The template supports all standard Smarty variables available in the order context, including billing/shipping addresses, line items, totals, and tax breakdowns.
