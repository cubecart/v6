# Invoice Template

Customise the HTML layout used when printing or emailing order invoices.

## Template Editor

The invoice template uses Smarty syntax. Edit the HTML to change the invoice layout, add your logo, or adjust the information displayed. The editor opens in source code mode for direct HTML editing.

## Restore to Default

Click **Restore to Default** to reset the invoice template to the original CubeCart layout. This overwrites any customisations. A confirmation dialog is shown before the restore is applied.

> [!TIP]
> The template supports all standard Smarty variables available in the order context, including billing/shipping addresses, line items, totals, and tax breakdowns.
