# Manufacturers

Manage product brands and manufacturers. Products can be filtered by manufacturer on the storefront, and coupons can be restricted to specific manufacturers.

## Manufacturer List

All manufacturers are listed with their name and action icons (edit, visit website, delete). Click a name to edit. Pagination is shown when the list is long.

## Add / Edit Manufacturer

### Manufacturer Details

| Field | Description |
| --- | --- |
| Name | The manufacturer or brand name (required, must be unique). |
| Website | The manufacturer's website URL. Shown as a link icon in the list if set. |

### Address

| Field | Description |
| --- | --- |
| Line 1 | Street address line 1. |
| Line 2 | Street address line 2. |
| Town | City or town. |
| Country | Country selected from a dropdown list. |
| State | State or province. |
| Postcode | Postal or ZIP code. |

### Contact

| Field | Description |
| --- | --- |
| Email | Contact email address. |
| Phone | Contact phone number. |
| Contact URL | Link to their contact or support page. |

## EU Contact Information (Optional)

Separate contact details for an EU-based representative, used for regulatory compliance (e.g. EU product safety regulations).

| Field | Description |
| --- | --- |
| EU Name | Name of the EU representative or entity. |
| EU Line 1 | Street address line 1. |
| EU Line 2 | Street address line 2. |
| EU Town | City or town. |
| EU Country | Country selected from a dropdown list. |
| EU State | State or province. |
| EU Postcode | Postal or ZIP code. |
| EU Email | EU representative email address. |
| EU Phone | EU representative phone number. |
| EU Contact URL | Link to the EU representative's contact page. |
