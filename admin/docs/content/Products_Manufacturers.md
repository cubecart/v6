# Manufacturers

Manage product brands and manufacturers. Products can be filtered by manufacturer on the storefront, and coupons can be restricted to specific manufacturers.

## Add / Edit Manufacturer

| Field | Description |
| --- | --- |
| Name | The manufacturer or brand name (required, must be unique). |
| Website | The manufacturer's website URL. |
| Address | Business address including town, country, state, and postcode. |
| Email / Phone | Contact details. |
| Contact URL | Link to their contact page. |

## EU Contact Information

Optional separate contact details for an EU representative, used for regulatory compliance.
