# Newsletters

## Newsletter List

View all created newsletters. Each row shows the newsletter subject with action icons to **Send**, **Edit**, or **Delete** the newsletter.

| Column | Description |
| --- | --- |
| Subject | The newsletter subject line. Click to edit. |
| Actions | **Send** (paper plane icon, with confirmation prompt), **Edit** (pencil icon), **Delete** (trash icon). |

> [!NOTE]
> If newsletters are disabled in store settings, a notice is displayed at the top of the list and the create form.

## Create / Edit Newsletter

### General

| Field | Description |
| --- | --- |
| Subject | The email subject line (required). |
| Sender Name | The "From" name. Leave blank to use the store name. |
| Sender Email | The "From" email address. Leave blank to use the store email. |
| Double Opt-In Only | When enabled, only sends to subscribers who have confirmed via double opt-in. In strict mode (when the lax subscribe option is not enabled), this toggle is locked on and cannot be changed. |
| Email Template | Optionally wrap the newsletter content in an existing email template. Select "None" to send without a template wrapper. |

### Email HTML

The newsletter body content. Use the rich text editor to compose your message.

### Send Test

Enter an email address and click **Save & Send Test** to preview how the newsletter will appear before sending it to your full subscriber list. The newsletter is saved automatically before the test is sent.

## Sending

Click the send icon next to a newsletter to begin distribution. You will be asked to confirm before sending begins. A progress bar shows the sending status. Newsletters are sent in batches to avoid server timeouts.

To cancel a send in progress, click the **Cancel Sending** link shown below the progress bar. You will be asked to confirm the cancellation. This returns you to the newsletter list.
