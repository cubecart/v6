# Newsletters

## Newsletter List

View all created newsletters. From here you can edit, send, or delete a newsletter.

## Create Newsletter

| Field | Description |
| --- | --- |
| Subject | The email subject line (required). |
| Sender Name | The "From" name. Leave blank to use the store name. |
| Sender Email | The "From" email address. Leave blank to use the store email. |
| Double Opt-In Only | When enabled, only sends to subscribers who have confirmed via double opt-in. |
| Email Template | Optionally wrap the newsletter content in an email template. |
| Email HTML | The newsletter content. Use the rich text editor to compose your message. |

### Send Test

Enter an email address and click **Save & Send Test** to preview how the newsletter will appear before sending it to your full subscriber list.

## Sending

Click the send icon next to a newsletter to begin distribution. A progress bar shows the sending status. Newsletters are sent in batches to avoid server timeouts.
