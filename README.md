# CubeCart

CubeCart is a free, self-hosted ecommerce platform written in PHP. Run an online store on your own server; CubeCart never takes a percentage of your sales.

![CubeCart storefront using the Atrium theme](.github/screenshot.jpg)

Try the storefront and admin on the [live demo](https://www.cubecart.com/demo).

## Requirements

- PHP 7.4 or later, 8.4 recommended
- MySQL 5.7+ or MariaDB 10.3+, using InnoDB
- Apache 2.4 works out of the box with the included `.htaccess`. Nginx needs [rewrite rules](https://kb.cubecart.com/getting-started/installation/configuring-cubecart-with-nginx).
- PHP extensions: mysqli, GD, SimpleXML, cURL, Zip, mbstring, fileinfo, DOM and OpenSSL

Full details are at [cubecart.com/requirements](https://www.cubecart.com/requirements).

## Installation

Download the latest package from [Releases](https://github.com/cubecart/v6/releases/latest), then follow the [installation guide](https://kb.cubecart.com/getting-started/installation/how-can-i-install-cubecart-v6).

## Upgrade

Back up your files and database first, then follow the [upgrade guide](https://kb.cubecart.com/getting-started/upgrading/how-do-i-upgrade-from-cubecart-v6-to-latest-v6).

## Extensions

Official extensions are free. Browse them at [cubecart.com/extensions](https://www.cubecart.com/extensions).

## Help

- [Community forum](https://community.cubecart.com): free help from other merchants and developers
- [Technical support](https://www.cubecart.com/technical-support): direct help from the CubeCart team for self-hosted stores
- [CubeCart Hosting](https://www.cubecart.com/hosting): managed hosting from the people who build CubeCart, with upgrades and support included

The GitHub issue tracker is for bug reports, not support requests.
