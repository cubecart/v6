CubeCart uses it for the email editor only (Documents > Email Templates). CKEditor remains the editor everywhere else.

Only what that screen loads is included: the core, the silver theme, the DOM model, the default icons, the link, lists, autolink and image plugins, the oxide and oxide-dark skins, and the default and dark content styles, as their minified files. To update, replace each file with the same file from a newer package.
